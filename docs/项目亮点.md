# IR 控制塔亮点

控制塔不接单、不拣货、不算账。它把十一套执行系统收成一张可以下指令的指挥面。日常操作见 [业务使用手册](./业务使用手册.md)。

1. **一屏指挥。** 总览同时看目标、资金、待审批和下一步动作。点执行就打到对应系统，一次最多 8 条。
2. **成本与效率可以当场换立场。** 保存滑块后重评预警，并作废与新立场冲突的待办。
3. **两套沙盘。** 人工沙盘改需求和资金后再决定下发；系统自动沙盘按综合分给推荐，默认只生成待办。
4. **资金盘按量级推演。** 10 万、百万、千万、亿、十亿，也可以自定义金额，并能一次跑完各档。
5. **自动平衡带护栏。** 可以关闭、只给建议，或只自动执行低风险决策。服务水平掉下去之后不再自动降本。
6. **一张订单看完整条履约链。** 追踪把订单、出库、运单、成本、预警和指令拼在一起。
7. **指令跨十一套系统，重复点击不会连发。** 结算系统只提供成本，控制塔不改它的账。
8. **节约和实账分开。** 页面上的节约是指令预计值。已经进入结算的运费，优先用结算数。
