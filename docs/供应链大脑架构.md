# 供应链大脑架构

> 详细构造以 [`供应链大脑构造.md`](./供应链大脑构造.md) 为准。本文只保留一张当前状态对照，避免再出现「SRM 预留 / 其它系统未接入」的过期描述。

## 当前接入范围

IR（`:8090`）已经注册并同步 **11 个执行系统**：OMS / WMS / TMS / BMS / SRM / SAP / BOM / INV / CRM / DMS / OA。默认 `MOCK`，切 `HTTP` 后走各系统 `GET /api/open/ir/snapshots` 与 `POST /api/open/ir/actions`。

缺货、预警执行建议、预测转指令、沙盘落地不再只打 SRM，而是由 `CoordinationService` 同时发给：

| 决策来源 | 协同指令 |
| --- | --- |
| 低库存 / 预测缺货 / 沙盘缺货 SKU | `SRM_PURCHASE_SUGGEST` + `SAP_CREATE_PR` + `OA_START_WORKFLOW` + `WMS_REPLENISH` |
| 经销商备件缺货 | 上述供应指令 + `DMS_REPLENISH_SHORTAGE` |
| 匹配到成品 BOM | 再加 `BOM_EXPLODE` |
| SRM 提交 PR / INV 提交开票 / CRM 升级工单 | 附带 `OA_START_WORKFLOW` |

`ActionEnricher` 会补全参数：SAP 低库存 bizKey `MAT-1000/1000/0001` 会还原成物料 `MAT-1000` 和数量，而不是把复合键当成物料号下发。

全链路追踪详情除 OMS→WMS→TMS 外，还带 `ecosystem`（与订单对得上的生态单据）和 `supplyRisks`（SAP 低库存、SRM 草稿 PR、DMS 缺货、OA 待办等）。

系统自动沙盘网格现为 13 套策略（原 10 套仓配/承运 + 供应前置 / ERP 物料拉动 / 经销商备件优先）。
