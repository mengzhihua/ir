一、系统定位与结论

IR 是供应链体系的「大脑」：聚合 OMS/WMS/TMS/BMS/SRM/SAP/DMS 七个系统的订单、库存、运单、成本、采购信号，围绕 5 项业务目标（单均成本 ≤¥25、OTIF ≥95%、NPS 估算 ≥50、缺货率 ≤5%、供应商准交 ≥92%）计算达成度，自动生成跨系统平衡决策；低风险动作在护栏内自动执行、高风险进入审批，所有下发都带幂等键、审计日志与失败/未知结果对账。二期（PR #6~#11）已全部合入默认分支。

三、在供应链体系中的位置与接口

IR 位于两层架构顶层：向下只读拉取各系统 Open IR 快照，向下写入协同动作；BMS 只读（成本），DMS 经 OMS 渠道间接受控，也可直接按缺货生成补货单。

对外 / 对内接口
接口方向说明
GET {system}/api/open/ir/snapshotsIR → 各系统（读）请求头 X-Api-Key；OMS 订单/库存/日销、WMS 出库/库存、TMS 运单/账单、SRM PR/PO/ASN/供应商、SAP 库存/采购/生产/未清项、DMS 缺货/补货单
GET bms/api/open/cost/records?from&toIR → BMS（读）成本记录，BMS 不接受写指令
POST {system}/api/open/ir/actionsIR → 各系统（写）统一动作口，请求体含 idempotencyKey；404 等可判定失败时回退专用口（OMS /hold /unhold /reroute /auto /cancel /prioritize；WMS /allocate /replenish；TMS /dispatch /sync-track /switch-carrier；SRM /purchase-suggest /submit-pr /approve-pr /expedite-po；SAP /create-pr /release-pr /release-mo；DMS /replenish-shortage /push-replenish）
登录模式回退IR → 各系统（写）无 API Key 时用接入配置账号登录后打业务口（如 OMS POST /api/order/{orderNo}/hold，WMS POST /api/inventory/replenish/transfer）；仓号 WH-SH/BJ/GZ 映射 WH01/02/03
POST /api/balance/run · /api/balance/decision/{id}/approve|reject前端 / 运维 → IR手动触发平衡、审批或驳回决策
/actuator/health运维 → IR健康检查
对下游：X-Api-Key（Open IR）或登录 token（回退）。对使用者：Authorization: Bearer <token>，响应统一 {code,msg,data}。生产需设置 IR_AUTH_SECRET 与 IR_ALLOW_PRIVATE_HOSTS=false（禁止指向内网/回环地址的接入配置）。

六、典型使用路径（讲解使用）

按以下顺序即可完整演示核心业务闭环。

  1. 控制塔看板：查看 KPI 卡片、预警与订单/运输图表，确认各系统快照时间。
  2. 业务目标：查看 5 项目标当前值/阈值/达成率，按需调整阈值与权重。
  3. 自动平衡：点「立即平衡」，查看生成的决策（策略、依据、预期节省、风险）；LOW 风险已自动执行，其余在「待审批」。
  4. 审批：对待审批决策点批准/驳回，批准后在「协同动作」看到下发记录与结果（SUCCESS / FAILED / 待对账）。
  5. 供应协同：查看 SRM 采购单/ASN、准交率，对滞后采购单执行催单，或从缺货建议一键生成 SRM 采购申请。
  6. 全链路追踪：输入订单号查看 OMS→WMS→TMS→BMS 的完整履约链。
  7. 运行历史：用「预计节省」与 OTIF/NPS 变化评估自动平衡效果。
关键状态流转
单据状态机 / 规则
平衡决策PENDING（待审批）→ APPROVED → EXECUTED / FAILED；或 AUTO 直接 EXECUTED；REJECTED 终止；冷却期内同目标不重复生成
协同动作CREATED → SENT → SUCCESS / FAILED / UNKNOWN（待对账）；重试复用原幂等键，UNKNOWN 不回补库存预占
运行模式OFF 不生成决策；SUGGEST 只生成不执行；AUTO 执行 LOW 风险且在护栏内的决策

八、常见问题、限制与生产配置

说明
主题内容
AUTO 会不会乱下单？只有 LOW 风险且在护栏内的决策自动执行；采购类有金额上限，降本类在 OTIF/NPS 低于服务护栏时暂停；其余都需人工审批。
下发超时怎么办？动作标记 UNKNOWN 待对账，不重复下发、不回补预占；对账确认后再收尾，重试复用原幂等键，下游按幂等键去重。
接入真实系统「系统集成」切 HTTP，填 Base URL 与 X-Api-Key；无 Key 时填登录账号回退业务口。启用前先看同步日志。
数据是真的吗？MOCK 模式为确定性演示数据；KPI 与「预计节省」为演示口径，生产以真实快照为准。
生产安全IR_AUTH_SECRET 必设；IR_ALLOW_PRIVATE_HOSTS=false；修改 admin 密码；接入 Key 用环境变量注入。
